四条规则，守住浪漫而不失专业。

净空以中央晨星直径为 1×。主标四周至少保留 1×，头像中图形占画布宽度 76%–82%。

01 · SOURCE

只有一个命令源

中央晨星是唯一金色源点。不得增加第二个中心、额外光环或装饰星群。

02 · ROUTES

始终保留六路

六条路径对应多个 Agent App 会话端点。不得删成单一路径，也不要添加更多造成噪声。

03 · COLOR

单色必须真一色

浅底使用 #162B5C，深底使用 #F7F9FC。不要用 CSS filter 临时生成单色。

04 · TONE

不回到卡通或暗黑

不加大眼、表情、爪、武器、霓虹外发光、黑暗面具或游戏阵营式徽章。
