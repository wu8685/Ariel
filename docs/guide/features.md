# Ariel 功能与使用指南

[文档导航](../README.md) · [安装与配置](../operations/agent-install.md)

## 继续原会话

1. 登录 Web，在左侧选择设备，再展开项目并选择会话。
2. 查看已有消息与实时输出，发送文字或图片；远程操作沿用桌面端当前权限。
3. 需要中断时点击停止；遇到审批或补充问题时，在会话里的对应卡片操作。

这不是新建一份远程聊天副本。Codex Desktop 仍持有原会话与执行状态；Desktop 离线或状态未确认时，已有内容可以只读展示，但发送、停止和审批会受限。

## 会话、草稿与未读

- 侧栏支持搜索、新建、重命名、置顶及归档；手机长按、桌面右键可打开操作菜单。
- 每个会话保留自己的输入草稿，切换会话不把另一会话的草稿带过去。
- 会话蓝点表示当前浏览器观察到更新、但尚未在最新位置成功查看；含未读会话的项目也显示蓝点。
- 蓝点不是 Codex 原生跨端已读状态：在 Codex App 或另一浏览器查看，不会自动清除当前浏览器的蓝点。首次观察已有会话只建立基线，不把全部旧会话标成未读。

## 模型与排队输入

在输入框操作栏选择模型、推理强度和速度。可选项来自当前设备与模型，设置从下一轮生效，不会替换正在运行的 turn。

会话运行时，可以继续编写并提交排队输入，再调整顺序、引导执行或删除队列项。排队展示文字不参与文本选择，编辑输入仍可选字；这些操作需要当前设备支持。

排队列表不会只保留四条：超过约四行的可见高度后，可在列表内部上下滑动查看后续项，并显示总条数。键盘可用 Tab 聚焦列表后按 End／PageDown 滚动；拖拽手柄上的方向键仍用于排序。显示不截断，提交容量仍沿用协议的 64 项安全限制。

### 停止后编辑

最后一条已停止的纯文本输入可以通过下方铅笔放回输入框，修改后重新发送。成功后由原生编辑链路替换对应 turn，不额外保留一条重复输入。

该能力仅在兼容性已验证且目标仍有效时开放；不支持附件，也不撤销已经发生的文件修改或其他副作用。执行结果不确定时不自动重发，先核对当前会话状态。

## 历史、实时更新与恢复

- 首次打开优先显示最近两个 turn；点击“加载更早消息”时，每次最多三个 turn，不一次拉取全部历史。
- 会话与应用切换优先复用已有缓存，再增量补充。缓存未命中、过期、身份变化或状态异常时，仍可能需要重新读取。
- 普通 streaming 正文默认每 5 秒合并更新；开始、完成、审批和用户输入等关键变化不等待这个窗口。
- 图片和工具详情按需加载；工具摘要保留在会话中，完整详情打开后再获取。
- 登录失效在原页面恢复，尽量保留正文和草稿；后台同步时发送按钮显示 loading，状态确认前禁用新的发送。

灰色重试提示表示 Codex 正在恢复网络；黄色表示需要关注，红色表示失败。协议不兼容时应刷新到匹配版本，不应反复登录或重发已经提交的操作。

## 文件与文档

文件功能默认关闭，需先按[文件配置指南](../operations/file-context.md)启用。

- **修改文件**：有真实文件变更来源的 turn 可显示文件卡片，分别打开原文或 Diff；删除文件和截断内容按实际结果提示。
- **正文引用**：点击有来源证明的文件引用打开内容，不根据文件名猜测任意路径。
- **工作区浏览**：从会话顶部文件入口浏览当前 workspace，逐层打开目录和文件，不递归下载整个目录。
- **原版／阅读**：原版展示可自动换行的文本；Markdown 可切换阅读模式，展示标题、列表、表格、代码和受控图片。Diff 仍是独立视图。
- **引用片段**：选中部分文本后，点击“引用到会话”带回输入框，确认后自行发送；文件变化会要求重新读取、重新选择。
- **图片**：本地 Markdown 图片接近可见区域时才加载；外部 HTTPS 图片需要你明确允许，失败只影响该图片，不刷新整个会话。

看到的原文是当前工作区版本，不是自动还原的历史提交；Diff 必须来自对应 turn 的真实变更，不能把当前 Git diff 冒充历史结果。版本兼容性与物理手机体验的未验项以[验收记录](../testing/)为准。

## 安全与使用范围

Ariel 当前为单用户模型，登录者可操作全部会话，没有 RBAC。PIN 只用于可信局域网；公网必须使用 HTTPS／WSS 和 Passkey，Agent 使用另一份高熵 token。

文件与会话正文可能包含敏感信息。基础功能不要求 Chilling、MySQL 或额外文件服务；不要为测试基础功能而停止承担其他任务的扩展服务。详细数据归属见[架构总览](../architecture/overview.md)。
