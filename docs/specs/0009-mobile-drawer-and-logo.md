# 0009：手机侧栏收起与灰色 logo

- 状态：Approved，用户于 2026-10-04 确认按此规格进入 TDD。
- 来源：2026-10-04 物理手机反馈：左侧菜单遮挡对话，期望点击菜单外空白处收起；logo 改灰色。
- 范围：Web 响应式布局与交互，不改变 Relay／Agent 协议。

## 输入、输出与行为

- 在宽度不超过 800px 的手机布局，侧栏打开时，在侧栏外的对话区域显示可点击的半透明 backdrop。点击 backdrop 收起侧栏；点击侧栏内部不收起；侧栏的关闭按钮仍可用。键盘 `Escape` 也收起侧栏。
- 点选会话后自动收起侧栏，露出完整对话面板；重新打开时保留当前设备和已选会话。宽屏保持双栏布局，不显示 backdrop。
- 顶部 Ariel 标志中的 `✳` 使用固定的中性灰色；文字、按钮、焦点和其他蓝色高亮维持 Night 设计。灰色应在深色顶栏上可辨认，不采用禁用态透明度。
- 打开侧栏按钮暴露 `aria-expanded` 和 `aria-controls`；backdrop 有可识别的关闭标签。移动端点击空白处不会误触发对话发送、停止或审批。

## 边界与错误

- 手机虚拟键盘、页面滚动及窄屏横向空间不应导致 backdrop 无法点击；侧栏关闭后对话与 composer 可操作。
- 不记录侧栏开合到本地持久化存储；刷新后的默认侧栏状态可按是否已有设备／会话决定，不能永久遮住对话。
- 不在桌面宽屏拦截对话区域点击。
