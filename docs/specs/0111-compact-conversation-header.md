# 0111：紧凑会话顶部

- 状态：Implemented（52px header 随 v0.9.0 部署；2026-10-27 入口位置调整已实现，待发布）。
- 目标：缩小顶部占用，把空间还给对话正文，不降低菜单与文件入口的可操作性。
- 范围：仅 Web 会话页 header；局部替代既有 66px 高度和字号约定，不改登录页、侧栏、文件阅读页、正文或 composer。

## 输入与输出

输入为当前会话标题、工作区路径、连接状态、文件浏览 capability、权限信息、viewport 与历史折叠状态。输出为可访问、可点击、宽度受 viewport 约束的紧凑 header；不改变网络请求或业务数据。

## 行为与不变量

1. 桌面与手机展开高度统一为 52px（原 66px），释放 14px；保留标题、路径两行及所有现有入口。
2. 标题 14px、路径 10px、两行间距 2px；菜单／文件／权限图标统一 18px。维持现有高对比深色样式，不缩小正文与输入字体。
3. 按钮点击区域仍为 44×44px；缩小视觉间距而不是牺牲触控面积。header 内垂直 padding 为 3px，横向 10px，控件间距 6px。
4. 标题和路径保持单行省略，不能把右侧文件／权限按钮挤出屏幕；320px、390px 与桌面均无横向溢出或控件交叠。
5. 历史折叠仍完整收起 header，不留死区；恢复后回到 52px。键盘弹起、streaming、输入焦点和草稿保留行为不变。
6. 权限弹层不能被紧凑 header 裁掉；文件浏览与侧栏仍能正常打开、关闭。保留 accessible name、键盘焦点和状态提示。
7. 标题／路径缺失时沿用现有占位；无文件／权限 capability 时不制造占位按钮。连接失败、warning／error、native 状态归属和发送能力均不变。

## 验收与错误边界

1. 先写并实际运行失败的样式与真实浏览器几何测试，再修改 CSS。
2. 真实 Chromium 手机 viewport／touch 与桌面测试：高度、字号、图标、44px 点击区域、长文本省略、无重叠／横溢、正文从 header 下面开始，以及菜单／文件／权限入口可用。
3. 固定手机 viewport 保存新截图基线；受影响的既有全页截图在逐项检查后更新。截图不能替代行为断言。
4. 回归历史折叠／恢复、移动键盘与 streaming、Web 全量 unit、browser suite 与 build。物理 iPhone／Safari 需另验，不能由 Chromium 模拟外推。
5. 本改动不增加 Agent／Relay 功能、协议、轮询或历史读取；不执行生产部署。

验收证据见 [0111 测试记录](../testing/2026-10-26-0111-compact-conversation-header.md)。

## 2026-10-27 入口位置调整（Approved）

用户明确指定：顶部右侧只保留文件浏览入口，靠右；当前权限／信息按钮移到输入框的加号旁。本次仅重排现有入口与弹层位置，未增加组件能力、权限写入、网络请求或通信语义，局部替代上述 header 保留权限入口的约定。

1. header 保留左侧会话菜单、标题／路径和最右侧文件浏览按钮；文件 capability 的原有显示条件不变，不留下权限占位。
2. 权限按钮紧跟输入框的附件加号，模型与发送仍在同一操作行；仍从当前 view 获取权限，不从缓存授权 mutation。
3. 当前权限原文、Full Access／未知警示、ARIA、展开／收起、外部点击和 Escape 关闭语义不变；无 view／mock 时保持隐藏。
4. 弹层改为从按钮上方向上展开，保持 12px viewport 边距与有界高度。必须脱离 composer／历史折叠的 overflow 裁剪；在 viewport、软键盘、输入区高度变化时更新位置，历史模式收起时关闭弹层，不能浮留在正文中。
5. 320／390／1280px、长标题／模型名、运行中＋编辑队列、软键盘缩小 viewport 均无重叠、横向溢出或图标遮挡；按钮点击区域不少于 44px。极窄且所有操作同时出现时可压缩模型入口内部间距／非必要 chevron，不能隐藏权限、强度／速度或发送操作。
6. TDD 先断言 header 不含权限且文件靠右、权限紧邻加号、弹层在上且可实际命中，再移动 DOM／改 CSS。补充真实 Chromium 和固定手机截图，回归草稿、历史折叠、权限开关、文件浏览和模型设置。
7. 不自动部署；实现与测试通过后按项目约定提交并 push，发布等待用户指示。

测试发现桌面已连接页面原有 620px 最小高度会在窗口缩小时将输入框挤出屏幕；本轮只让 `.app-shell.connected` 的最小高度归零，保持登录页面既有最小高度。此项用于保证入口和弹层在缩窗后的可操作性，不改变滚动／缓存策略。

操作栏仅在纵向收起／恢复时保留 padding 动画，不再插值横向 padding，避免桌面→窄屏缩放过程中临时挤压按钮。模型入口至少 44px；最拥挤的 360px 以下编辑队列状态压缩内部间距并省略装饰 chevron，强度／速度图标保留。
