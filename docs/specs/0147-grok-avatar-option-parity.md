# 0147：Puck 头像与侧边栏对照截图

- 状态：Implemented（2026-11-10）
- 日期：2026-11-10

## 输入

用户提供的两张暗色截图是可见效果的依据：

1. 头像选择器：13 个形状，按 4 + 4 + 5 排列；11 个色块，按 6 + 5 排列。第一块是白色，不是纯黑。
2. 左侧列表：普通 Bot 行用头像外接框相对名字墨色高度的比例，不把截图像素当成 CSS 像素。群聊行是成员头像叠放、名称和真实最后一条预览。截图里的蓝色「未读」浮层不属于这一行。

形状和颜色 id 仍沿用此前核对过的 Grok Bot 标识。标识不决定轮廓或色值。选择器不再列出截图里没有的形状。已保存的其余形状 id、`black` 和 `#rrggbb` 继续可读，并归一到最接近的调色板 id。

## 行为

1. 普通展示没有存在光环。选择器上的选中描边只表示当前选项。
2. 可见形状顺序：团块、云、方形、闪光、四叶、心、花、水滴、胶囊、楔形、房子、星、六边形。轮廓来自截图蓝色蒙版的外轮廓，再做平滑；细小缺口会被简化。
3. 眼睛是一对略微倾斜的深色圆角胶囊，位于脸的右上方，并跟头部动作一起移动。
4. 可见颜色及取样色值：白 `#ffffff`、棕 `#8c6640`、红 `#ea4045`、橙 `#ed702d`、黄 `#f19d38`、绿 `#5ac67a`、青 `#54b9a6`、蓝 `#3c82f6`、紫 `#895bf5`、品红 `#eb4698`、灰 `#777777`。`black` 仍可保存为 `#000000`，但不出现在选择器里。
5. `image` 为 https URL 或 png/jpeg/webp data URI 时显示照片。改形状或颜色不会丢掉它。没有新增上传入口。
6. 侧边栏名字字号保持 14px。头像槽改为 44px，因为截图里圆形头像外接框与名字墨高之比约为 132/42 = 3.14，`14 × 3.14 = 44`。头像到名字的间距改为 17px，对应截图里约 51/42 = 1.21 个名字墨高。行高仍是 96px，侧边栏宽仍是 280px。这是比例换算，不是物理尺寸。
7. 群聊列表行用成员头像叠放，最多四个；超过四个时第四格显示剩余人数。顺序沿用成员 position。预览使用该群最后一条真实消息，没有消息时显示成员名。不伪造预览，也不复制未读浮层。

## 未核对

1. 轮廓是截图外轮廓的简化，不是客户端网格投影，不能称为逐像素一致。需要同一套静止 SVG 或更高分辨率的正面参考才能继续收紧。
2. 眼睛的倾斜和位置按截图目测，没有逐像素套准。
3. 侧边栏 44px / 17px 由 14px 字号乘截图比例得到。截图设备的像素比未知，不能宣称与 Grok Bot 的物理大小相同。
4. 群聊叠放采用三人和四人等分槽位。截图顶部「工作机 bots」的大头像看起来更大，因为那是照片内容，槽位本身按等分实现。
