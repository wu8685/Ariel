# 0049：登录页 Logo 与精简标题同排展示

- 状态：Implemented（138 个 Web 单测、9 个真实 Chromium 用例、桌面与手机截图、production build 已验；物理 iPhone/Safari 待用户复验）。
- 范围：未连接登录首页的品牌文案、Logo/标题排版、桌面与手机真实浏览器回归。
- 依赖：[0048 登录页彩色 Logo 恢复紧凑尺寸](0048-compact-color-login-brand-mark.md)；不改变 Logo 资产或显示尺寸。

## 用户结果

登录首页不再展示换行的口语化大标题。彩色 Logo 与精简标题组成同一横向品牌 Lockup，在桌面和手机宽度下均保持单行关系，减少首屏垂直占用并改善视觉秩序。

## 文案与布局契约

1. 大标题从“继续你的工作，不必守在电脑前。”精简为“接续 Codex”。
2. 彩色 Logo 位于左侧；`PRIVATE ACCESS` 与大标题位于右侧的文字区，三者共同放入 `.connect-hero` 横向容器。
3. `.connect-hero` 不换行；大标题自身也不换行。1440×900 桌面与 390×844 手机视口中，Logo 必须在标题左侧，且两者垂直范围相交。
4. Logo 保持 0048 定义的响应式尺寸：桌面 160px、手机 128px；正式彩色资产、可访问语义和加载优先级不变。
5. 连接说明、连接码输入和连接按钮保留；手机不得出现横向滚动，表单仍可达。

## 验收

1. TDD：先增加新标题和同排几何断言，并确认旧标题／上下布局失败。
2. 修改 JSX 与 CSS 后，运行桌面和手机登录页真实 Chromium 用例，更新两张截图基线并人工检查。
3. 运行 Web 全量单测、全部 Playwright 用例和 production build；物理 iPhone/Safari 待用户复验。

## 实现结果

1. 登录页大标题已精简为“接续 Codex”，移除原先的两行口语化文案。
2. 新增 `.connect-hero` 横向 Lockup：彩色 Logo 位于左侧，`PRIVATE ACCESS` 与单行标题位于右侧；桌面和手机均通过不换行及几何相交断言。
3. 1440×900 与 390×844 截图基线已更新并人工检查；手机无横向溢出，连接码表单正常可达。
4. Web 全量 138 项单测、9 项真实 Chromium 用例和 production build 均通过。
