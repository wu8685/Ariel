# 0042：排队项更多菜单的紧凑字体与排版

- 状态：Implemented（主题契约、390×844 Chromium 计算样式／几何／截图、Web 全量测试与 production build 已验；物理 iPhone/Safari 待用户复验）。
- 范围：Ariel Web 的排队项、排队项“更多”菜单及其与 composer 相邻时的视觉层级；不改变排队、编辑、移动、删除或引导的行为语义。

## 问题

排队项的“更多”菜单通过 Portal 挂载到 `body`。它因此不会继承队列操作区的紧凑字号；菜单按钮也未显式重置浏览器原生外观。在手机浏览器中，菜单回退成 16px 字号和灰色系统按钮，与 12px 的排队正文及 Night 主题不一致。

## 用户可见行为

1. 菜单文字与排队正文保持同一 12px 视觉层级，不再使用浏览器默认 16px 字号。
2. 菜单按钮使用 Ariel Night 主题的透明底、弱化文字、圆角 hover／focus 状态，不显示原生灰色按钮外观。
3. 菜单宽度和行高保持紧凑，但每项仍有不低于 34px 的可点击高度。
4. 排队区继续保持“正文 12px、操作 11px、辅助信息 10px”的层级；composer 正文继续与会话正文保持 14px，不因本次调整缩小。
5. 菜单仍位于 composer 上方，不产生横向溢出或遮挡；编辑、上移、下移的可用状态与行为不变。

## 不变量与边界

- Portal 的挂载位置保持不变；菜单必须依靠自身完整样式，而不是依赖祖先继承。
- 桌面与手机共用菜单排版，手机 viewport 不额外放大。
- 键盘 focus 轮廓、disabled 状态和语义化 `role=menu/menuitem` 保持可用。

## 验收

1. 主题契约测试先证明当前菜单缺少 12px 字号与显式按钮重置，再由实现转绿。
2. 390×844 Chromium touch fixture 断言菜单及菜单项计算字号为 12px、按钮背景透明、菜单不遮挡 composer。
3. 更新并人工检查手机截图基线，确认菜单、排队项和 composer 的字体层级及间距协调。
4. Web 全量测试、真实浏览器 UI 测试和 production build 通过；物理 iPhone/Safari 仍由用户最终复验。
