# 0030：工具调用折叠文字入口

- 状态：Implemented（自动测试、production build 与 390×844 浏览器样式验收通过；物理手机待用户复验）。
- 来源：工具详情折叠后只留下一个 44×44px 圆形箭头，视觉过重且占用正文空间；用户希望改为一段稍灰的文字，点击后仍展开当前内容。
- 范围：Web 会话正文中每个 turn 的工具活动折叠入口；不改变活动归类、数量、展开内容、交错顺序、实时追加、分页、运行状态或协议。
- 与既有规格的关系：本规格覆盖 [0021](0021-single-icon-tool-activity.md) 的圆形 icon 外观和 44×44px 触控尺寸要求；0021 的单入口、可访问名称、展开范围与状态保持规则继续有效。

## 输入、输出与行为

1. 折叠态不再显示圆形边框或箭头 icon，改为低对比度文字“使用了 N 个工具”；N 是本 turn 当前已加载的 activity 数量。
2. 文字本身仍是原生 button，可通过点击、Enter、Space 展开；accessible name 和 title 继续使用“打开工具调用（N 项）”，`aria-expanded=false`。
3. 展开后现有详情、顺序和样式不变；入口文字改为“收起工具调用（N 项）”，再次激活后恢复折叠文案。
4. 入口使用透明背景、无边框、12px 中性灰文字和清晰 focus outline；不得再保留 SVG 箭头或 44px 圆形占位。
5. 实时追加 activity 时，数量和可访问名称同步更新，当前展开状态与稳定锚点保持不变。

## TDD 与验收

1. 先写失败的组件测试：折叠态显示“使用了 3 个工具”、没有 SVG，点击后显示收起文字和原有三项内容，再次点击恢复。
2. 先写失败的样式测试：入口无边框、透明背景、低对比度文字、小字号，且不再强制 44×44px。
3. Web 全量测试、production build 与 Go 回归通过；在真实浏览器检查折叠入口尺寸、颜色、展开／收起、无横向溢出。物理手机由用户最终复验。
