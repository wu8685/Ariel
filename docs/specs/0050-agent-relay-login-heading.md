- 状态：Implemented（138 个 Web 单测、9 个真实 Chromium 用例、桌面与手机截图、production build 已验；物理 iPhone/Safari 待用户复验）。
- 范围：未连接登录首页的品牌标题、响应式字号、桌面与手机真实浏览器回归。
- 覆盖：[0049 登录页 Logo 与精简标题同排展示](0049-inline-login-brand-lockup.md)中的“接续 Codex”文案；横向 Lockup、彩色 Logo 和其他布局契约保持不变。

## 用户结果

登录首页以“Agent 联络中继器”描述 Ariel 的产品定位。标题继续与彩色 Logo 同排，不因文案变长而换行、溢出或挤压连接表单。

## 实现契约

1. 一级标题精确改为“Agent 联络中继器”，不保留“接续 Codex”的产品界面引用。
2. `.connect-hero` 与标题继续 `nowrap`；Logo 保持桌面 160px、手机 128px。
3. 标题字号采用更紧凑的响应式范围：手机 24px，桌面不超过 34px，以保持同排关系。
4. 1440×900 桌面与 390×844 手机视口中，Logo 必须位于标题左侧，两者垂直范围相交；页面不得产生横向滚动。
5. `PRIVATE ACCESS`、连接说明、连接码表单及其他品牌资产不随本规格改变。

## 验收

1. TDD：先将桌面和手机 E2E 的标题预期改为“Agent 联络中继器”并确认失败。
2. 修改文案与响应式字号后，更新桌面和手机截图基线并人工检查。
3. 运行 Web 全量单测、全部 Playwright 用例和 production build；物理 iPhone/Safari 待用户复验。

## 实现结果

1. 登录页一级标题已改为“Agent 联络中继器”，产品界面不再引用“接续 Codex”。
2. 标题字号调整为 `clamp(24px, 2.4vw, 34px)`；390×844 手机使用 24px，1440×900 桌面使用 34px。
3. 桌面和手机截图中，Logo 均位于标题左侧且标题保持单行；手机无横向溢出，连接表单正常可达。
4. Web 全量 138 项单测、9 项真实 Chromium 用例和 production build 均通过。
