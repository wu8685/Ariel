# 0007：Night 界面配色

- 状态：Draft，等待用户确认后进入 TDD 与实现。
- 来源：用户于 2026-10-04 要求黑底、白字、蓝色高亮。
- 范围：Ariel Web 的现有页面；不改变 Relay、Desktop Agent、协议或会话行为。

## 用户可见结果

- 页面默认使用固定 Night 配色，不依赖系统亮暗模式；此次不新增主题切换开关。
- 顶栏、会话列表、正文区、输入框与连接遮罩均使用近黑或深灰背景，正文为高对比的白色／浅灰文字。
- 蓝色用于品牌标记、主按钮、选中会话、链接和键盘焦点等主要高亮；状态色仅用于明确语义（例如危险权限警示、错误、在线状态），不把警示伪装成普通高亮。
- 基础配色以 `#0B0F16` 页面背景、`#121923` 内容表面、`#F3F7FF` 主文字、`#B4C0CF` 次级文字和 `#60A5FA` 蓝色文字／焦点为起点；蓝底白字主按钮须达到普通文本至少 4.5:1 的对比度。微调数值不改变“黑底、白字、蓝色高亮”的方向。
- 历史、loading、离线、权限警示、待审批／补充问题、输入禁用与操作失败的可读性不低于普通会话状态。
- 手机窄屏布局与现有交互保持，文本不溢出；`prefers-reduced-motion` 继续生效。

## 实现边界与验收

- 保留现有 DOM 结构与交互行为，集中使用 CSS 色彩变量表达背景、表面、边框、文字、蓝色 accent 和语义状态。
- TDD：先写样式契约测试并运行到 red，验证 Night token 和关键控件使用；然后改样式到 green。构建必须通过。
- 浏览器检查至少覆盖桌面宽屏、390×844 手机视口，以及连接、已选会话、Full Access 警示、待回答卡片和 disabled 按钮。检查可见焦点与对比度，不仅凭构建通过宣称完成。
