## 1. 用户行为

1. 从 turn 修改文件、正文文档引用、工作区文件树或 Markdown 相对链接打开文件，均进入同一文件 Tab 工作区。不同文件不相互覆盖；相同设备／epoch／来源 identity 重复打开默认聚焦已存在的 Tab。
2. 不设固定 Tab 数量上限。超过可用宽度横向滚动；提供可搜索的全部标签列表，大列表有界渲染，允许搜索和逐页查看。不得因第 5／33／101 个 Tab 拒绝或静默关闭。
3. 宽屏时文件工作区和主会话并排、均可独立滚动和交互，不遮住主会话 composer。窄屏上下分区，并提供收起恢复入口；短屏与软键盘优先保证 composer 可用，不产生横向页面溢出。
4. 工作区整体收起不关闭 Tab；展开恢复激活文件、原版／Markdown 阅读／Diff 模式、各模式滚动位置及可确认的捕获选区。切换 Tab 同样保留状态。无需保留浏览器原生 Range 或已加载图片 Blob。
5. 关闭一个 Tab 不影响其他文件、主会话草稿或执行；关闭当前项后激活相邻项，最后一项关闭后释放工作区。返回会话／Escape 只收起，不关闭全部标签；Escape 仅在文件工作区焦点范围内生效。
6. 本阶段不显示新对话入口、不创建 thread、不 fork、不发送消息。
7. 文件引用仅在用户显式点击“引用到会话”时准备：保留现有主会话草稿，引用成功后收起工作区。来源 thread 必须等于当前 thread；主会话切换后仍可阅读原文件，但禁止错会话引用，不改写 threadId。

## 2. 输入与状态

- Tab 输入：设备 ID／Agent epoch、来源 thread／turn／item、path 或原始 reference、模式／定位行；来源身份是只读请求和缓存的边界，不由当前全局选择猜测。
- Tab 轻量状态：稳定本地 tabId、来源 descriptor、标题、原版／阅读／Diff、滚动、选区 source offsets／范围、请求状态与 generation。
- 文件内容／Diff：共享有界 LRU；不把每个打开文件的全文复制到 Tab 状态、持久存储或日志。
- 主会话切换不关闭文件 Tab，引用权限随当前 thread 核对。设备／Agent epoch 切换、安全注销及重写历史可清理受影响资源与标签，迟到读取不得恢复已清理标签。
- 刷新页面不保证恢复 Tab；不改变已有会话草稿、最近两个 turn 或历史每页最多三个 turn 的规则。

## 3. 资源与错误

1. Tab 数量与缓存预算分离。正文与 Diff 合计沿用 8 MiB、10 个缓存资源的有界 LRU，只挂载一个激活正文；缓存淘汰不关闭 Tab。再次激活仅按原来源按需重读。
2. 收起时不挂载正文／Markdown／图片，停止相关派生资源工作。缓存命中时展开／切换不重复读取；缓存失效后仅加载激活项。
3. 文件读取结果逐 Tab 关联 identity／generation。打开 A 后打开 B，A 的迟到响应只能更新 A，不能抢焦点；关闭／注销后的响应忽略。重复激活 loading Tab 不重复读。
4. 失败只影响目标 Tab，保留其他 Tab 和主会话，提供显式重试。不得触发登录循环或 native mutation。
5. 文件 SHA 变化清理旧选区、重置滚动与阅读状态并提示。后台不持续轮询文件；既有 turn 文件变化通知使对应缓存失效，下一次激活按需重验。
6. 多 Tab 不新增 WebSocket、thread watch／follower 或轮询，不预读全部后台文件；现有权限／能力 flag、路径／SHA／引用校验与 lazy 图片限制继续有效。
7. 精确选区只保存 offset／行范围等轻量信息，内容由经 SHA 校验的正文重建，不把任意长选区文本作为每 Tab 永久副本。
