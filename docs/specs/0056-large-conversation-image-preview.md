# 0056：超高分辨率会话图片按需生成安全预览

- 状态：Implemented（真实超高分辨率文件、自动测试、移动 Chromium 与截图已验）。
- 范围：Desktop Agent 会话图片读取与预览缩放、Web 图片失败提示、自动／真实文件／移动浏览器验收。
- 不涉及：远程图片抓取、SVG／GIF 支持、修改原始图片、把图片正文持久化到 Relay、任意浏览器路径读取。

## 已确认原因

截图中的原始会话消息引用本机绝对路径下的 PNG。文件仍存在、格式有效、大小为 2,038,568 bytes，但尺寸为 `7990 × 7225`，约 5773 万像素；现有 `validateImageBytes` 为控制解码内存拒绝超过 2500 万像素的图片，因此 `thread.image` 返回 `INVALID_ARGUMENT`。Web 捕获异常后只呈现统一的“截图未能加载”，隐藏了具体原因。

## 用户结果

用户点击仍然存在的超高分辨率 PNG/JPEG 时，Ariel 在 Desktop Agent 端生成适合浏览器展示和放大的预览，不修改原文件，也不把原图预先塞入会话 snapshot。无法加载时，按钮显示可理解的失败原因并保留重试入口。

## 输入、输出与处理边界

1. 输入仍必须来自目标 Agent App 的原始会话 item；Web 只能提交 `threadId`、`turnId`、`itemId` 与 `imageIndex`，不能指定文件路径。
2. 本地文件或原生 data URI 仍只接受 PNG／JPEG，压缩数据必须大于 0 且不超过 4 MiB。
3. 尺寸不超过现有展示预算且最长边不超过 4096px 时，返回原始字节，不做无损耗的重复编码。
4. 超过展示预算但来源不超过 6400 万像素时，在 Desktop Agent 内按原宽高比缩至：最长边不超过 4096px、总像素不超过 2500 万；PNG 仍编码为 PNG，JPEG 仍编码为 JPEG。
5. 来源超过 6400 万像素、解码失败、输出超过 4 MiB，或格式／文件状态不合法时，继续拒绝；不得仅抬高浏览器解码上限。
6. 图片缩放一次只允许处理一个请求，使单用户 Web 的并发点击不会按请求数叠加大图解码内存。
7. 输出继续使用既有 data URI 和 8 MiB WebSocket frame 边界，不改变协议字段和 Relay 状态归属。

## 错误呈现

1. `NOT_FOUND` 显示“原图片文件已不存在”。
2. `INVALID_ARGUMENT` 显示“图片格式、尺寸或内容不受支持”。
3. `HISTORY_TOO_LARGE` 显示“图片超过安全传输上限”。
4. 断线、超时和其他既有错误复用当前错误映射。
5. 图片按钮保留“点此重试”，错误文字不得包含本机绝对路径或原始错误堆栈。

## 不变量

1. Relay 与 snapshot 仍不保存图片正文；只有用户点击或进入原生图片自动加载范围后才读取。
2. 不抓取 `http://`／`https://` 图片，不支持浏览器传入文件路径，不扩大 Markdown 链接导航权限。
3. 原始图片只读，缩放结果只存在于当前响应内，不覆盖、不创建旁路文件。
4. 现有上传图片仍沿用 4 MiB、2500 万像素和最多 3 张的校验；本规格只放宽“读取已有会话图片”的预览路径。

## 验收

1. 先新增失败测试：大图展示尺寸计算、缩放后的格式／尺寸、来源像素硬上限、Web 失败原因和当前真实图片 fixture。
2. `7990 × 7225` 的当前本机 PNG 经真实文件只读测试可返回有效 PNG data URI，预览最长边不超过 4096px、像素不超过 2500 万、数据不超过 4 MiB。
3. 既有普通 PNG/JPEG 返回内容不变；SVG、远程 URL、缺失文件、超限压缩数据继续拒绝。
4. Go 全量测试、`go vet`、Web 全量单测和 production build 通过。
5. 真实移动 Chromium fixture 点击超高分辨率引用后显示图片并可打开 lightbox；失败 fixture 显示具体原因且可重试。物理 iPhone/Safari 保留用户复验。

## 实现结果

Desktop Agent 现在为会话中已存在且不超过来源硬上限的 PNG/JPEG 按需生成等比例预览，并串行执行图片处理；上传校验与协议结构没有放宽。Web 将协议错误映射为不泄露本机路径的可操作提示，lightbox 通过 portal 挂载到页面顶层，避免在 Markdown 段落内生成非法 DOM。完整证据见 [0056 验收记录](../testing/2026-10-08-0056-large-conversation-image-preview.md)。
