## 用户结果

首次打开仓库的人可以快速理解 Ariel 解决什么问题、如何组成、怎样在局域网中启动和使用，以及去哪里查看深入文档。README 保持简短、自然、可扫描，不再像实现日志、验收报告或 Agent 生成的说明集合。

## 信息架构

README 只保留以下主线：

1. 顶部新版 Logo、项目名和一句话定位。
2. “Ariel 是什么”：说明使用背景、核心能力与状态归属。
3. “架构”：用一张 Mermaid 图说明浏览器、Relay、Desktop Agent 与 Codex Desktop 的关系。
4. “快速开始”：前提、首次启动、查看地址和连接码。
5. “基本使用”：连接、选择会话、换网重启和停止服务。
6. “安全边界”：可信局域网、明文 HTTP/WS、Desktop 当前权限和私有 IPC 兼容性。
7. “深入阅读”：链接到安装、架构、兼容性、规格与测试文档。

## Logo 契约

1. README 第一个可渲染元素仍是居中的新版 `web/public/brand/ariel-logo-wind-messenger-color.png`，显示宽度为 360px。
2. 图片自身保持透明背景；README 不给图片或容器设置背景色、滤镜、底板、裁切或阴影。
3. 自动测试除 RGBA 类型外，还须解码 PNG 像素，确认四角 alpha 为 0、存在透明像素且存在非透明主体。
4. README 不出现品牌故事、品牌使用规范或工程化品牌规范链接；详细品牌资料仍可留在 `docs/brand/`，但不占用项目入口叙事。

## 内容边界

1. README 不展开手动构建、环境变量、探针实验、逐版本验收和故障矩阵；这些内容链接到 `docs/`。
2. 快速开始必须提供可复制的 `git clone`、`up local`、`status`、`show-pin`、`restart-local` 与 `stop` 命令。
3. 保留必要的安全警示，但不重复底层协议和测试证据。
4. README 总长度控制在 100 行以内。
