# 0022：提高 Night 主题黑白对比

- 状态：Implemented（用户于 2026-10-06 明确要求设计后直接开发；自动与本机静态浏览器已验，物理手机待验）。
- 来源：现有灰黑、灰白组合显得整体失活，像网络断开；用户要求黑白更纯、蓝色继续克制。
- 范围：Web 手机和桌面共用主题。覆盖 0007／0018 的具体中性色值，不改消息左右布局、语义色、交互或协议。

## 视觉规范

1. 会话画布和页面基底用纯黑 `#000000`；最主要的标题、正文与可操作文字用纯白 `#ffffff`。侧栏、输入框、Codex 气泡沿用无蓝色偏色的中性深灰，但相对纯黑画布有清楚边界。浏览器 `theme-color` 与页面基底一致。
2. 次级文字仍要与背景明显区分：普通次级文字至少达到 7:1；微型 meta、placeholder、活动图标及 disabled 控件可相对弱一些，但最低 4.5:1，不能用“整体发灰”表达连接状态。真正离线／不可用仍由明确状态文案、状态点和禁用交互表达。
3. 蓝色只保留用户气泡、可点击主操作、已选会话、链接与焦点；在线绿、风险橙保留语义。用户蓝底白字、Codex 深灰底白字都满足普通文字至少 4.5:1。hover、focus、disabled 和手机触控状态仍可辨。
4. 输入区、侧栏和消息边界在手机、桌面都应清晰，不增加占屏面积，不牺牲历史内容展示。Logo 维持中性灰，不重新变绿。

## 验收

- 先更新主题测试使旧色值失败，再调整 CSS；测试检查关键 token、文字与气泡对比度、非蓝中性面板、`theme-color`、连接状态语义与活动图标可读性。运行 Web 全量测试和构建，在浏览器查看手机／桌面宽度及已连接、离线视图。
