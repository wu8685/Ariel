0130 曾写右侧信息栏可收起，且宽度小于 1280 px 时默认收起。现行 Puck 工作区改为：Bot 配置栏在所有日常宽度下默认收起。1280 px 以上不再自动展开。

## 输入

当前选中的 Bot 或群聊，以及左侧栏上的右键目标：Bot 行、群聊行、分组标题或空白处。

## 输出

两列或三列的 Puck 工作区。配置栏关闭时，对话区吃掉空出的宽度，消息仍按现有 `720px` 内容宽度居中。配置栏打开时恢复现有三列，栏内名称、说明、头像、权限、授权规则和删除入口保持原行为。

## 行为

1. 打开 Puck，或用普通点击切换 Bot / 群聊时，右侧 Bot 配置栏收起。不把打开或收起写入 localStorage、数据库或其他跨刷新偏好。
2. 在左侧栏的 Bot 行上右键，菜单有「编辑」。点「编辑」会选中该 Bot 的会话（若尚未选中），并打开该 Bot 的配置栏。
3. 配置栏打开后可以关闭。栏头有「关闭助理信息」。Esc 在没有搜索、加号菜单、其他右键菜单、对话框或头像页占用时，同样关闭配置栏。头像页自己的 Esc 只关头像页。
4. 栏内既有操作保持可用：编辑头像、编辑说明、运行权限、以后都允许、删除 Bot。头像页仍是固定 4+4+5 形状、11 色 6+5、「上传」「重置为默认」，「生成」只解释、不发起生成。
5. 空白处右键仍只有「建分组」。分组标题右键仍是重命名和删除分组。群聊行不出现 Bot 的「编辑」。
6. 分组交互不变：长按后拖动换分组，行上没有分组下拉，「未分组」仍在，删除分组只取消归属。加号菜单里仍是「新建助理」和「建群」，搜索仍在加号旁边。
7. 手机上配置栏仍是从右侧滑入的抽屉。标题「查看助理信息」和「更多助理操作」继续打开当前会话的信息；桌面同一按钮也打开已收起的配置栏。

## 不变量

- 不持久化配置栏开关。刷新或重新进入后，Bot 会话再次以收起开始。
- 不实现头像生成，不改动态眼睛。
- 不把 Chilling、任务状态或 Codex 会话库卷进这条布局。

## 错误处理

右键目标不是 Bot 行时，不打开 Bot 配置，也不显示「编辑」。关闭配置栏不修改 Bot 资料。

## 验收

1. 普通 Bot 会话初次显示和切换后，配置栏不在无障碍树中，工作区没有 `info-open`。
2. Bot 行右键出现「编辑」；点它后，该 Bot 被选中且配置栏打开，头像入口可点。
3. 「关闭助理信息」和符合上面条件的 Esc 会再次收起。
4. 空白处右键仍是「建分组」。群聊行和分组标题不出现 Bot「编辑」。
5. 重新挂载后配置栏仍收起，localStorage 不新增开关键。
