# 0011：手机会话紧凑布局与 Night 视觉

- 状态：Approved（2026-10-04，用户确认 0011；Web 实现与浏览器验证通过，物理手机待验）。
- 来源：2026-10-04 用户希望手机 UI 上方文字和区域缩小，将 Read Only／Permission 等提示收成点击后查看的 icon，并把 Ariel logo 所在的整行 header 收进左侧菜单；随后提供 Codex 手机版截图作为对话 UI 的视觉参考。
- 范围：宽度不超过 800px 的会话工作台顶部、对话区域及输入区；沿用 [Night 配色](0007-night-appearance.md) 和 [移动侧栏](0009-mobile-drawer-and-logo.md)。不改变 Relay／Agent 协议或宽屏布局。

## 现状与目标

- 390×844 浏览器视口中，品牌栏 60px、会话标题区 97px、无警示的权限条约 35.5px，总计约 193px；对话滚动区约 494px。
- 紧凑版在手机会话页取消独立品牌栏和常驻权限条，仅保留约 64–68px 的会话标题区。在同一视口与内容下，默认顶部总高至少减少 100px，增加的空间归对话滚动区，不挤占输入框。
- 视觉参考取截图中的层级和形态：近黑的连续画布、白色标题与正文、灰色次要信息、低对比炭灰色圆形／胶囊控件、贴近底部的圆角输入区。蓝色仍用于明确的可操作或选中状态，灰色 logo 与琥珀色安全警示保持原有语义。不要复制手机系统状态栏，也不要把截图的加载空白当成目标内容样式。

## 输入、输出与行为

- 手机已连接的会话页不再显示独立的 Ariel／Relay 顶栏。Ariel logo、完整连接状态和“断开”入口移入左侧菜单顶部；菜单关闭时，会话标题区的菜单按钮保留一个随 Relay 状态变化的状态点，其可访问名称包含连接状态。
- 手机会话标题区是一行紧凑工具栏：左侧 44px 以上的圆形菜单按钮，中间两行标题／工作目录，右侧 44px 以上的权限信息按钮。菜单按钮延续现有“打开侧栏”行为，不伪装成返回上一级；权限按钮使用低对比炭灰色圆形或短胶囊外形。标题与目录字号及行高适度缩小；隐藏非必要的 `CODEX SESSION` 装饰标签。连接前的登录页仍显示 Ariel 品牌和清楚的连接状态，但不占用已连接会话的垂直空间。
- 长标题与目录继续单行省略显示；DOM 中保留完整文字，不能因紧凑布局覆盖按钮或发生横向溢出。
- 手机会话标题区只保留一个权限信息 icon，取代常驻的 `Read Only`／`Full Access`／审批策略文字。点击 icon 打开浮层，显示当前 Desktop sandbox、approval policy 和原有风险警示全文；浮层覆盖而不挤压对话区。再次点击、点浮层外或按 Escape 关闭。手机不依赖 hover；宽屏继续显示现有权限条。
- `Full Access` 或状态未知时，icon 持续显示琥珀警示色，不能仅在浮层打开后才显警示；Read Only 等普通状态使用中性色。icon 有完整状态的可访问名称、展开状态和关联浮层。浮层文字可滚动，不被屏幕边缘裁切。
- 权限信息 icon、侧栏入口、断开按钮至少保持 44px 的可点击区域；夜间模式颜色、焦点样式和宽屏布局不变。菜单内的“断开”执行现有清除 Web session 的动作，连接前的登录页不能因顶栏移走而失去品牌或错误提示。真正需要用户决定的命令／文件／权限审批卡片仍在会话中完整显示，不收进这个 icon。
- 软键盘弹出、窄屏和横屏下，顶部栏不能压住对话或输入区；会话正文与输入区仍可正常滚动、操作。
- 手机对话区保持近黑、低装饰的连续背景。真实历史消息、运行中状态和交互卡片须照常显示；不为模仿参考图而留出大片固定空白。可缩小消息间过大的留白，但不得压缩到难以区分角色、回合和需要响应的交互。文字仍可选择、复制，长代码／路径不能撑出横向页面。
- 手机输入区改成靠近屏幕底部的炭灰色圆角胶囊：空草稿时以单行高度展示，输入多行时自然增高至约四行，之后仅输入框内部滚动。发送与停止仍是清楚可触达的真实操作，按钮最小触控区域 44px；保留 Enter 发送、Shift+Enter 换行和输入草稿。通知或错误出现时不能遮挡输入，iOS safe area 与软键盘弹出时仍能操作。桌面输入区不变。
- 参考图中的“新建会话”、更多菜单、附件和语音入口不属于本规格；在对应能力真正实现之前，不放置无功能按钮。底部的文件／增删行统计也不根据消息文字猜测；当前协议无可信统计字段时不显示。手机系统状态栏不由 Web 页面模拟，截图中的加载指示不能替代明确的加载或错误状态。
