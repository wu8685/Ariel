# 0034：项目会话分组默认收起与按需展开

- 状态：Implemented（自动测试与 production build 已验；物理手机待用户复验）。
- 前置：0032 已按规范化完整 `cwd` 将左侧会话组织为“项目 → 会话”两级结构。

## 用户可见行为

1. 左侧每个项目初始均为收起状态，只显示项目名、完整路径、会话数量和展开指示；项目内会话默认不渲染。
2. 点击某个项目标题只展开该项目，再次点击将其收起；其他项目的状态不变，允许同时展开多个项目。
3. 展开／收起只影响左侧导航的可见性，不切换、关闭、取消订阅或修改当前已选中的 Codex 会话。
4. 搜索与分页后的项目继续使用同一交互规则：新出现项目默认收起；用户已展开且仍在当前列表中的同一路径项目保持展开。
5. 切换设备时清空展开状态，新设备的所有项目重新默认收起；不把本机绝对路径或展开偏好写入浏览器持久化存储。

## 交互与可访问性

- 整个项目标题区域都是按钮，手机端保持足够点击面积。
- 按钮使用 `aria-expanded` 表达状态，并通过 `aria-controls` 关联会话容器。
- accessible name 同时包含动作、项目名与完整路径，保证同名不同路径项目可区分。
- 收起状态不依赖动画完成，不使用不可见但仍可聚焦的会话按钮。

## 状态边界

- 展开状态仅存在于当前 Web 页签的 React 内存中，不进入 Ariel 协议，不改变 Relay、Desktop Agent 或 Codex SSOT。
- 状态 key 继续使用 0032 的规范化完整路径；未知项目使用现有稳定分组 key。
- streaming update、队列变化、会话标题更新和列表刷新不得自动展开项目或重置同设备的展开状态。

## TDD 与验收

1. Web 测试确认多个项目默认全部收起，项目内会话按钮不在 DOM 中。
2. 展开一个项目后只出现该项目的会话；再次点击后隐藏；另一个项目保持原状态。
3. 按钮的 `aria-expanded`、accessible name 和 `aria-controls` 与实际内容一致。
4. 现有搜索、项目计数、会话选择、移动侧栏、全量 Web 测试和 production build 不回归。

## 非目标

- 不提供“全部展开／全部收起”总开关。
- 不跨刷新、跨标签页或跨设备保存展开偏好。
- 不改变项目排序、项目识别或会话排序。
