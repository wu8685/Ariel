# 0114：设备选择与侧栏会话层级优化

- 状态：Implemented（2026-10-27 用户授权联合发布；Web／Chromium viewport＋touch／build 已验，物理 Safari 待复验）。
- 日期：2026-10-27。
- 范围：Ariel Web 侧栏设备选择、项目／会话层级及导航文字选择行为。
- 关联：0032／0034 项目分组、0036 置顶分区、0068 长按菜单、0075 重命名／置顶及 0022 Night 主题。
- 本规格独立于未批准的 0106：不顺带改反馈语义、其他 select 或全部 action menu。

## 1. 用户可见目标

1. 设备选择框与展开列表使用页面已有的深色面板、边框、字号、圆角和 focus 色，不再在手机上弹出风格不同的系统选择器。
2. 设备选择框与侧栏顶部 toolbar 留出 10px 间距；展开列表与选择框之间留出 6px 间距。
3. 项目展开后，子会话相对项目名有清楚的右缩进，并通过略浅的深灰底色体现父子关系；不改变对话正文的纯黑底色。
4. 长按会话只打开操作菜单，不同时选中文字或显示系统复制浮层；普通点击、侧栏滚动、右键和键盘菜单保持可用。

## 2. 输入与输出

- 设备选择输入沿用现有 `devices`、`deviceId`、连接状态及 `setDeviceId` 路径；设备 ID 仅作值和稳定 key，不用于推断名称或权限。
- 输出仍为用户明确选中的 deviceId；展开、移动焦点、关闭菜单不提交设备切换。
- 会话与项目输入继续使用现有分组、展开、置顶、未读及选中状态；不增加列表请求、订阅或持久化状态。
- 禁止设备选择时关闭弹层并禁用触发器；保持当前设备、正文与草稿的既有连接恢复语义。

## 3. 设备下拉组件

### 3.1 外观

- 用页面内的单选 listbox 替换侧栏原生 `<select>`；新建会话的项目 select 不在本次范围。
- 触发器显示设备名、现有设备状态点及统一 chevron；高度至少 40px，弹层 option 点击高度至少 44px，字号沿用 12px 紧凑体系。
- 弹层使用现有中性 panel／raised、border、muted／text 及 accent token；选中项用勾选和强调色共同表达，hover／focus 可区分，颜色不是唯一信号。
- 弹层与触发器同宽，最多占用 viewport 可用高度并内部滚动；保持在侧栏与遮罩之上、不被侧栏裁切、不横向溢出。设备很多时不撑高整个侧栏。
- 长设备名截断展示但保留完整可访问名称；不得挤掉状态点和选择标记。离线设备仍可按现有规则选择，不擅自改变业务门禁。

### 3.2 行为与可访问性

- 触发器有“设备”可访问名称、`aria-expanded`、`aria-haspopup="listbox"` 和状态描述；listbox／option 提供当前选中态。
- 点击／Enter／Space 打开；方向键导航，Home／End 到首末项，Enter／Space 明确选中，Escape 关闭并返回触发器；Tab 可正常离开且关闭，不困住焦点。
- 打开后优先定位当前设备，非提交式焦点移动不触发 `setDeviceId`；重新选中同一设备不重新加载列表。
- 点击外部、侧栏收起或连接不允许操作时关闭；组件卸载清理监听和定位资源。
- 设备更新时按 deviceId 保留有效焦点；焦点设备消失则回退到有效项，空列表显示“暂无设备”且不能提交虚构设备。未选择设备的提示态与既有流程兼容。
- 不自动重试设备切换，不改变设备切换时的缓存、超时、草稿或 fencing 逻辑。

## 4. 项目／会话视觉层级

- 侧栏项目标题维持现有 surface 深灰；展开的子列表使用略浅的中性深灰（建议新增侧栏专用 token `#171717`），不修改全局 `color-page`。
- 子列表整体向右缩进约 20px，子会话标题的起点至少比项目名称向右 12px；不绘制子列表左侧竖线，依靠缩进与底色表达归属，不新增图标或信息行。2026-10-27 用户明确要求移除该装饰线，本次按此范围直接实施，不改变展开、选中或置顶行为。
- hover、已选会话及蓝色未读点仍清楚可辨，选中态不能只靠颜色表达；保留现有蓝色边框／侧边强调。
- 项目路径、数量、未读标记和展开箭头不丢失；长标题在剩余宽度内截断，320px viewport 不横向溢出。
- 置顶区继续独立展示，不误缩进成某个项目的子节点；项目默认收起、搜索分组、计数、排序、去重和分页语义不变。

## 5. 长按不选中文字

- 对会话行及其标题、日期、摘要等导航文字设置局部 `user-select: none`／`-webkit-user-select: none`，配合 `-webkit-touch-callout: none` 避免系统复制浮层；可对项目导航标题使用同样规则。
- 不在整页或整个 sidebar 上设置禁止选择，避免影响搜索框；重命名输入框、发送框、正文及文件选区仍可正常选取／复制／编辑。
- 保留 500ms 长按阈值、移动超过 10px／滚动／pointercancel 取消、长按后 click 抑制；不要用整个 pointerdown 的 `preventDefault` 或 `touch-action: none` 来牺牲侧栏滚动。
- 不清空正文中既有的 Selection，不给所有导航项设置 `readonly` 等无效属性，不改变按钮的可访问性。

## 6. 错误处理与安全边界

- 设备／会话列表错误沿用现有错误和恢复路径；视觉与交互改动不新增 mutation、后台刷新、自动重放或网络协议。
- Codex 仍是会话 SSOT；不改 Relay、Desktop Agent、权限、认证或缓存边界。
- 设备弹层与会话操作菜单不得相互遮挡导致无法关闭；必要时打开一个时关闭另一个。
- 用户于 2026-10-27 已授权完成全部能力后联合 push 与双端部署；保留回滚版本并验证本机 Agent、公网 Relay／Web。

## 7. TDD 与验收

先增加测试并实际运行 red，再实现 green，最后整理样式和重复逻辑：

1. 组件测试覆盖设备选择打开／关闭、当前项、键盘导航、单次提交、同设备不重复提交、外部点击、禁用、空列表、选项消失及长名称。
2. 既有设备切换测试改用用户可见的 listbox 操作，保留设备缓存与超时的原有断言，不能只更换选择器后删掉业务回归。
3. 主题测试检查顶部间距、子级缩进／专用背景 token、子列表无左边框、选择限制的局部作用域及输入框／正文不受影响；320／390／1280px 浏览器检查实际 border-left 为 0，同时保留缩进与底色差异。
4. 真实 Chromium 在 320／390／1280px 下断言几何关系：设备框与 toolbar 至少有 10px 间距、子会话文字比项目名至少缩进 12px、弹层与长标题不越界。截图覆盖收起／展开、设备列表、选中与未读状态。
5. 手机 touch viewport 验证长按打开菜单、后续不误切换、侧栏仍能滚动且滚动取消长按；额外验证文字不可通过用户选择手势选中，不能只靠合成 pointer 事件宣称原生选择已验证。
6. 桌面验证右键／Shift+F10、键盘选择设备、菜单焦点与 Escape；重命名输入仍能按片段选择文本，正文复制不受影响。
7. 所有浏览器写请求只走隔离 WebSocket fixture，不操作真实 Codex 会话；执行全量 Web 单测、production build 及浏览器回归。
8. Chromium 手机 viewport／touch 验收不等于物理 Safari；iPhone 的系统复制浮层最终需用户复验，不将 CSS 支持推断当作真机证据。
