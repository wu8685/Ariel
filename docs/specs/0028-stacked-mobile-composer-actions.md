# 0028：手机输入框与操作栏上下分层

- 状态：Implemented（自动测试、production build 与 390×844 隔离浏览器验收通过；物理手机待用户复验）。
- 来源：用户在物理手机上观察到运行中“停止”按钮占用输入文字宽度，希望停止只显示 icon，并把附件、停止、发送操作移到输入文字下方。
- 范围：宽度不超过 800px 的 Ariel Web composer；不改变宽屏布局、发送／停止／截图语义、Relay／Agent 协议或 [0014](0014-mobile-composer-newline-and-eight-lines.md) 的一至八行自适应规则。

## 输入、输出与行为

1. 手机 composer 改为上下两层。上层 textarea 独占整行可用宽度，不与附件、停止或发送按钮横向竞争；长草稿、自动折行和一至八行增长继续按 0014 工作。
2. 下层是独立操作栏：附件“＋”位于左侧；停止和发送位于右侧。操作栏不得覆盖 textarea，也不得因运行中出现停止按钮而改变 textarea 宽度。
3. 运行中停止按钮只显示停止 icon，不显示“停止”文字；按钮仍保留 `停止` 的可访问名称和提示，继续精确中断当前 active turn。icon 不得使用空白文字模拟。
4. 发送按钮继续只显示现有发送 icon，禁用态、一次发送、空草稿限制与截图发送行为不变。附件、停止和发送按钮均保持至少 44×44px 触控区域。
5. composer 继续位于手机 safe area 之上；软键盘、窄屏、长 placeholder 和 streaming update 不得造成横向溢出、输入区高度往返或正文抖动。
6. 宽度大于 800px 的桌面 composer 保持现有单区布局和可见文字，不随本规格改动。

## TDD 与验收

1. 先写失败的 DOM 测试：运行中停止按钮可通过名称找到、包含独立停止 icon、点击仍发出唯一 `turn.interrupt`。
2. 先写失败的移动样式测试：composer 为纵向布局；textarea 占满整行；操作栏占满宽度；附件靠左，停止与发送靠右；手机端隐藏停止文字；三个按钮触控区域至少 44px。
3. 保留 0014 的输入高度、Enter 行为、发送失败草稿和 VisualViewport 测试，并回归 streaming 布局稳定性。
4. Web 全量测试和 production build 通过；在 390×844 隔离浏览器核对 textarea 与 composer 左右边界、按钮位置、运行前后宽度稳定和无横向溢出。物理手机由用户最终复验。
