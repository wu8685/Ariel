## 当前验证

本次新增竞争与中断过期探针后，`go test -race ./...`、`go vet ./...` 与 probe 二进制构建全部通过。补充回答串行链路、双客户端不同答案竞争、中断过期本地拒绝与 command cancel 的 exact-turn 中断均获真机证据；允许路径和其他审批类型仍未验证。

当前覆盖率：CLI 15.8%、App Server 58.3%、Desktop IPC 62.5%、probe 65.6%。新探针的真实进程与 Desktop wrapper 拉低了单元测试覆盖率；核心回答与状态映射有确定性测试，但 wrapper 故障注入仍需补足，不能用真机成功掩盖这些缺口。诊断错误文本也先加失败测试，再区分 command approval 与 user-input，避免误报交互类别。

```sh
go test -race ./...
go test -cover ./...
go vet ./...
go build -o bin/ariel-probe ./cmd/probe
```

真实链路结果和未验证项目见 [兼容性报告](../compatibility/2026-10-03-m0.md)。Go 单元测试使用合成数据与 `net.Pipe`；默认 `go test` 不连接真实 Desktop，也不创建测试聊天。

覆盖率仅用于暴露缺口，不能代替兼容性测试。目前 CLI 与真实进程/fixture 驱动主要通过显式真机探针验证，仍需增加确定性故障注入测试。M0、首版审批和手机体验均未宣称全部完成。
