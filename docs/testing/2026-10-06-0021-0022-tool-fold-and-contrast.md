# 0021／0022 工具折叠与 Night 对比度实施记录

- 规格：[0021 每回合一个图标](../specs/0021-single-icon-tool-activity.md)、[0022 纯黑白 Night](../specs/0022-crisp-black-white-night.md)。用户要求写好规格后直接按 TDD 开发。
- 范围：Web 渲染和样式；不修改原会话、Agent、Relay 协议、凭据、审批与发送语义。

## Red → green

先改 Web 组件测试：一个 turn 内由 Codex 正文隔开的三条活动必须默认完全不可见，只留下一个无可见文案、带 accessible name 和数量的图标；点击后与正文按原顺序交错显示，再次点击全部隐藏；实时追加保持同一展开状态。实际运行出现 4 个组件失败。另将主题测试改为纯黑背景、纯白主文字、中性灰面板和触控图标要求，实际运行出现 2 个主题失败。浏览器预览又发现禁用的连接按钮仍为蓝色，先补失败的主题测试再修复。

实时追加同组调用时，原控件的末条 item 锚点会变化；补充测试先观察该失败，再给控件稳定锚点。实现后，`web/` 的 `npm test` 12 个文件／87 项通过，`npm run build` 通过，`git diff --check` 通过。构建仍有原有单 chunk 超过 500 KiB 的性能提示，不影响本次功能。

## 浏览器与部署边界

本机隔离的静态预览在桌面宽度检查了纯黑基底、白色主文字和灰色禁用连接按钮；390×844 视口的 DOM 检查为宽 390、文档无横向溢出，连接表单宽 350，色值为纯黑和中性灰。该静态预览没有连接 Relay，不能算工具折叠的真实会话可视验收；折叠行为由 Web 组件测试覆盖。临时预览标签与服务已关闭。

现有 LAN Relay 无需重启；它按请求读取 `web/dist`，构建后只读 HTTP 检查确认 8080 页面已指向新 JS/CSS 资源，Agent 的握手和原凭据未变。手机需刷新页面验证视觉与折叠交互；真实业务会话未被发送、停止或审批。
