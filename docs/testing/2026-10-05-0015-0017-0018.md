## 隔离浏览器验收

在仅监听本机 loopback 的临时 Relay 与 Mock Agent 中，用测试 PIN 打开隔离会话，并在 1280×720 与 390×844 视口检查。实测主正文背景为近黑色，用户气泡蓝色且靠右，Codex 气泡中性深灰且靠左；手机发送按钮完整落在视口内，文档没有横向溢出。测试消息只发送给 Mock，会话页正常出现双方正文。临时标签页与两进程均已关闭，视口恢复。

另起只监听 `127.0.0.1:8096` 的临时 Relay 和新构建的真实 Desktop Agent，对已有大会话做**只读**浏览器复验。首次显示 10 个 turn、85 组工具活动、142 条非折叠消息条目；活动组默认没有详情卡片，点击一组后按顺序出现 5 条详情，收起后按 Enter 可再次展开。点击“加载更早消息”后显示 20 个 turn、146 组活动，页面无错误提示或横向溢出。本报告不记录实际会话正文、工具参数、路径及 owner ID；临时标签和服务均已关闭，手机当前使用的 LAN 服务未重启。

这证明真实工具历史的归类、折叠和按需旧页读取在本机浏览器可用，但**不能**证明阅读旧历史时真实新消息到达的滚动表现，也不能代替物理手机验收；这些仍列在 `docs/TODO.md`。0016 自动上滑请求旧页仍暂缓，旧历史继续由按钮按需加载。
