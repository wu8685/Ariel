# 2026-10-27：排队消息完整列表与内部滚动

## 范围与根因

- Issue #37；按用户直接授权的 [0120](../specs/0120-scrollable-full-queue.md) 实施。
- 原实现完整 map `queuedMessages`，没有四条数据截断；协议已有 64 项安全限制，本次保持不变。
- 原暂停标题与列表各自限高，列表不参与父面板的剩余高度分配。390×390 viewport 实际列表 bottom=288.609375、面板 bottom=278，超出约 11px，会被输入区裁切。
- 改为纵向 flex 面板、不可收缩的标题／提示、可收缩且 `min-height: 0` 的内部滚动列表；标准可见列表最大 180px，较矮 viewport 继续收缩。超四项提示总数，完整数组仍全部渲染。
- 仅改 Web 展示；不增加网络请求、follower、mutation 或状态存储，不依赖／操作 Chilling。
