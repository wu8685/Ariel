## 实现范围

- Web 同一 SPA／WebSocket 提供「会话／任务看板」、管理库／执行主机分离、建卡／状态操作／反馈／未读／原生会话跳转。保留原会话草稿与阅读位置。
- Ariel 不读 DSN、不连接 MySQL；管理 gateway 经私有 Unix HTTP 连 chilling。manager-only 无需本机 Codex。
- 后台 dispatch／track／validate／receipt／fact 与 Web 请求域隔离；每设备独立 token，管理库与执行目标 allowlist，执行机再检查允许管理源／工作目录，native 写入共享原 Service。
- 默认关闭。Chilling／DB 的失联只撤回任务 readiness，恢复可经同一 WS 更新 capability，不以重启普通会话作为恢复手段。
- 官方配置 gate 只读检查 account、effective project provider／endpoint 和已绑定 thread provider／cwd；没有 model catalog 即有额度的推断。cmd 对未验证 native IPC profile 禁止自动任务写入，但不改变原会话或只读 tracking。
- 进展只上传固定状态和白名单工具计数；同状态内容变化默认 10 分钟节流，状态变化即时。原生正文／工具详情／路径不自动发布。
